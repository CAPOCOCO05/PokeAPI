## Descripcion
Pokedex construida sobre React y TypeScript que consume la API oficial Pokemon (PokeAPI)
Contiene distintas **funcionalidades** como:
  - Visualizar detalles caracteristicos de cada pokemon
  - Marcar y visualizar pokemones favoritos
  - Realizar filtrado por tipo pokemon
  - Hacer busquedas por nombre 

-----------------------------------------------------------------------------------

## Tecnologias utilizadas:
React: Libreria principal para interfaces basadas en componentes
TypeScript: Tipado estatico para asegurar la robustez del codigo
Vite Herramienta de empaquetado y servidor de desarrollo ultra rapido
CSS: Estilizado modular e interactivo sin dependencias externas

-----------------------------------------------------------------------------------

## Instrucciones de instalacion

Pasos para clonar y configurar el proyecto de forma local en tu computadora:

1. Clonar el repositorio:
    git clone [https://github.com/CAPOCOCO05/PokeAPI.git]
    
2.  Acceder al directorio del proyecto:
    cd pokeapi
    
3.  Instalar todas las dependencias requeridas:
    pnpm install

-----------------------------------------------------------------------------------

## Comando para ejecutar el proyecto

Una vez completada la instalacion, puedes levantar el servidor local con el siguiente comando:
    pnpm run pikachuyoteelijo
